# C_L1｜三维云密度驱动的地面云影：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：体积范围求交＋密度光程积分＋Beer–Lambert。约束映射：F03, F04。前级：无。

## 1. 目标与边界

给定有限三维云密度场和方向光，计算空间查询点到光源方向的透射率，并在地面形成对应云影。结果应正确响应密度、云体变换和太阳方向，不能用独立滚动暗噪声代替。

不重建天空、不生成云动力学，不要求多次散射或建筑遮挡。给定密度是输入资产，不是预计算云影。查询点允许在地面、云体内部或其他合法空间位置。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| C_L1-N01 零密度 | 非零 box，但 rho=0 | tau=0,T=1 |
| C_L1-N02 均匀云 | 已知长度和常密度 | 解析 tau/T |
| C_L1-N03 分层密度 | 沿一轴不同层值 | 分段中点采样 |
| C_L1-N04 非均匀云 | 不对称体积、多个空间点 | 三维类型和坐标 |
| C_L1-N05 斜方向光 | 不与轴平行的 L | 区间长度与透射 |
| C_L1-N06 内部起点 | 查询点位于云内 | 从 s=0 积分 |
| C_L1-N07 未命中 | 点/方向不穿云体 | 空区间契约 |
| C_L1-N08 平行边界 | 一轴或两轴方向分量为零 | 稳定 slab 判定 |
| C_L1-N09 分段关系 | 均匀/对齐分段路径 | T_total=T1*T2 在同积分划分下 |
| C_L1-N10 整体平移/旋转 | 同一场和点作对应刚体变换 | 结果不变、世界长度正确 |


这些是覆盖类别，不是已跑的 10 个输入。作者固定实际数值/种子，另给不重合的公开开发样例。失败时保存逐输出误差和原始值；不只返回一个布尔。

## 5. 参考结果与独立性

CPU 参考实现独立 slab 求交、三线性采样、中点求和；先以均匀盒解析结果校验。正式 OJ 比较给定 N 的离散结果，不偷偷与 N→∞ 的积分比。分段透射关系在相同采样划分或解析均匀场中检验，避免不同离散采样制造伪失败。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 7. 必须构造的错误对照

1. 地面贴一张独立噪声。
2. 把 3D 场当 2D 切片。
3. 只算密度不乘物理路径长度。
4. T 错误作用于所有环境光。
5. 光线起点在云内仍从负距离开始。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 云影位置随云场和太阳变化。
2. 密度/厚度变化反映在遮光程度。
3. 相机移动不拖动世界云影。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
