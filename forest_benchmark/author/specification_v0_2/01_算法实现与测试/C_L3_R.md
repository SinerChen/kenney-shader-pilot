# C_L3_R｜既有噪声资源复用与原天空保护：实现与集成检测

**作者侧，禁止作为模型解题材料。** 文档规格已补充；源绑定、Godot实现、测试和阈值尚未执行/冻结。

前级：C_L2；约束：F03。前级算法契约v0.1不改；本级接入定义v0.2是新增作者规格，不是原森林代码事实。

## 1. 目标和前级角色

使用森林工程中指定的既有噪声资产构造局部云密度，并接入前级云影与薄雾体积光。正确解释资源及数据约定，保持原天空及其他既有消费者不变。本变体不要求局部云场与天空动画同步。

本级10组集成覆盖不是10道新算法OJ。另回归本链C_L1/C_L2各10个数值组以及C_L2的5组联动，独立记录。

公开判题定义：[本级契约](../03_测试模型Prompt/公开契约/C_L3_R.md)、[L3公共契约](../03_测试模型Prompt/公开契约/01_L3公共接入契约.md)、[L1](../03_测试模型Prompt/公开契约/C_L1.md)、[L2](../03_测试模型Prompt/公开契约/C_L2.md)。

## 2. 原工程事实边界

旧报告的查找线索：`Main.tscn（报告记录 3D TGA / 2D BMP 噪声引用，具体资源路径待核验）`。

具体噪声文件名、导入类型/布局/采样、维度和所有消费者未闭合。不得凭文件扩展名编造 Texture3D 或 Texture2D 数据，也不得默认两份资源已可重分发。

构建前必须补齐：

1. 找到报告所述两类资源的真实路径、资源类、原导入设置和天空消费者；没有所需资源时不换生成噪声却仍称 native。
2. 在固定引擎中验证原始数据的线性采样、尺寸、切片和轴向；为输入取值提供可复核元数据。
3. 验证前级云影和薄雾可在选定真实接收区局部接入且不改原天空/环境；局部云盒与雾盒不相交。
4. 原天空可在统一时钟下建立稳定回归基线，新增资源副本/派生缓冲不会污染共享消费者。

只把完整核验记录写入对应source_binding，不自行把这些线索升级为verified。场景细节见[C_L3_R场景规范](../02_场景文件与资源/C_L3_R.md)。

## 3. Codex参考实现职责

这不是再训练一套云算法。作者将原资源只读挂载，验证导入产物后独立解码原始源/导入数据，建立 U/V 采样 oracle。模型需读取实际 typed 资源，生成 rho_grid 并驱动继承核心；不能由公共桥预先把资产转换成正确 3D 浮点密度后交付，那会消除本级主要考点。公开允许等价转换，不能强迫一种 sampler/实现路径。

需要新建的作者产物：`author/references/C_L3_R/`中的独立参考与GPU合格集成；`author/cases_private/C_L3_R/`的正式输入/答案；`author/judges/C_L3_R/`的oracle及采集；`author/mutations/C_L3_R/`的反例；`starters/C_L3_R/`的净化完整工程。这些是目标路径，不是已经存在的实现。

## 5. Oracle与误判控制

CPU/受控独立采样对照检查原资源多个非对称坐标和层边界；源数据经官方导入后的数值应先与解码参考校准，避免将压缩差异当模型错。密度与下游 tau/fog 以实际合法 U/V 原值计算。资源消费者图与关显示诊断用来验证原天空保持；不使用模型自报的 type 字符串判正确。

直接按资源类型采样或创建数值等价的私有派生资源均合法；禁止的是破坏原消费者或更换目标输入，不是数据转换本身。压缩/过滤误差按独立参考标定，不能隐藏精确未压缩答案去判合法导入结果。

按照[通用L3协议](02_L3集成检测通用规范.md)验证GPU实际资源、正常计算与显示一致性；用[工具协议](../04_作者侧流程与评测/05_L3工具与检测协议.md)分离公开诊断和私有裁判。

## 6. 必须构造的错误对照

1. 按普通二维图采样本应具有层组织的数据。
2. 交换深度与高度轴，或在切片间不进行规定采样。
3. 为适配新 shader 修改共享输入的导入类型。
4. 使用同外观的自建噪声而不读原资源。
5. probe 读取正确资产，但画面使用固定云影纹理。

为每个反例记录至少一个预期拒绝的G组，执行后保存证据；不能只写“应该能测出”。至少另一种合法实现或组织应通过，避免裁判只识别作者文件结构。

## 7. 视觉与保护rubrics

1. 局部云影和雾体确实变化且保留前级光学关系。
2. 新增显示关闭后，原天空/植被与基线一致。
3. 相机运动时雾与不透明场景合成没有明显穿插错误。

采用原包0–4锚定视觉等级和固定相机/时刻采集；最终视觉阈值先标定后冻结。数值、核心联动、静态/运行时保护失败不由视觉分抵消。

允许：新建 solution 中的派生资源、密度处理、局部云影接收材质和薄雾合成；只读访问原天空噪声。

禁止：改共享噪声/导入/天空材质、用其他噪声替代、改全局方向光强度/曝光/AA、影响非目标接收物。

## 8. 输出与发布

真实输出至少包括：`source_resource_samples`, `derived_density_grid`, `cloud_and_fog_outputs`, `original_sky_consumer_snapshot`。数据必须关联实际资源、坐标、格式、对象ID和tick，并与画面干预同步，不信任模型自己填写的pass/fail。

发布前仍需冻结：verified_resource_paths_types_layout, sample_filter_and_color_space, density_construction_parameters, local_light_receiver_scope, original_consumer_baseline。依照[L3门禁](../04_作者侧流程与评测/06_L3发布门禁与评分.md)运行全项。缺源/不具备观测条件标阻塞，不部署只包含题面但没有工程的任务。
