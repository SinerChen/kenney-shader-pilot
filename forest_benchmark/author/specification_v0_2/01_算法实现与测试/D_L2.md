# D_L2｜固定接触源的泡沫输运：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：半拉格朗日平流＋固定源项＋衰减。约束映射：F05。前级：D_L1。

## 1. 目标与边界

继承流向水纹，新增固定接触源生成的泡沫。泡沫应按相同输入流场做半拉格朗日输运并衰减，生成源保持在接触位置；移动源不能让旧泡沫瞬移。

不求河流绕障碍、浅水高度或真实泡沫化学。泡沫为二维标量场；接触物体由测试端给出合法锚点，不考碰撞检测。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| D_L2-N01 空场 | f=0,S=0 | 保持零 |
| D_L2-N02 静水有源 | v=0,decay=0 | dt*S 和空间核 |
| D_L2-N03 纯平移 | 均匀 v,S=decay=0 | 回溯方向与插值 |
| D_L2-N04 曲线流 | 非均匀速度 | 局部 v(s) 回溯 |
| D_L2-N05 衰减 | v=S=0 | exp(-decay*dt) |
| D_L2-N06 源位置/尺寸 | 多个 source/radius/rate | 世界锚点和核半径 |
| D_L2-N07 入流边界 | q 出域 | 取0不 wrap |
| D_L2-N08 饱和 | 大合法源率 | clamp，不产生负值 |
| D_L2-N09 停源/移源 | 多步移动后关闭 | 旧状态不跟源瞬移 |
| D_L2-N10 分辨率/重放 | 不同公开 dx/dz、reset | 物理尺度一致，按离散值比较 |


这些是覆盖类别，不是已跑的 10 个输入。作者固定实际数值/种子，另给不重合的公开开发样例。失败时保存逐输出误差和原始值；不只返回一个布尔。

## 5. 参考结果与独立性

CPU 参考实现相同回溯和边界采样。常量场内部、无速度纯指数衰减、单源核作解析对照。严格守恒不作为此方法必然指标；错误对照要由离散输出和源锚点判定，不凭总量略减判断失败。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 6. 联动/回归

| 组 | 受控干预 | 要求的关系 |
|---|---|---|
| D_L2-I01 只改图案 | 改变 K/phi/P，固定真实速度及源 | 锚点/泡沫状态不随图案参数漂移 |
| D_L2-I02 改实际速度 | 反转/转弯同一输入流场 | 水纹表达与泡沫方向按各自定义响应 |
| D_L2-I03 静水 | v=0 | 停止搬运，源/衰减仍生效 |
| D_L2-I04 停源 | S=0 | 旧泡沫继续输运/衰减 |
| D_L2-I05 移动源 | 固定既有 f，改变 source | 新源位置改变，旧 f 不瞬移 |

## 7. 必须构造的错误对照

1. 源与滚动 UV 共用坐标。
2. 只有源遮罩没有持久状态。
3. 移动源时整体搬移泡沫图。
4. 改平铺率后泡沫物理速度改变。
5. 使用前向采样方向。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 接触源稳定、泡沫从源向外输运。
2. 改流向后轨迹变化可辨。
3. 旧泡沫与新生泡沫连续，不是独立滚动白纹。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
