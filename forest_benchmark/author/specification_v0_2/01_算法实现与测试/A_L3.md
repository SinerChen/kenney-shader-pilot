# A_L3｜森林树木灼烧与余烬的跨表示集成：实现与集成检测

**作者侧，禁止作为模型解题材料。** 文档规格已补充；源绑定、Godot实现、测试和阈值尚未执行/冻结。

前级：A_L2；约束：F01。前级算法契约v0.1不改；本级接入定义v0.2是新增作者规格，不是原森林代码事实。

## 1. 目标和前级角色

将前级灼烧、焦化及前沿余烬接入指定森林树木。在相机远近切换、目标暂时离开画面以及多个实例并存时，维持每棵树自己的灼烧状态和发射历史；保留原植被运动、轮廓和非目标树木。

本级10组集成覆盖不是10道新算法OJ。另回归本链A_L1/A_L2各10个数值组以及A_L2的5组联动，独立记录。

公开判题定义：[本级契约](../03_测试模型Prompt/公开契约/A_L3.md)、[L3公共契约](../03_测试模型Prompt/公开契约/01_L3公共接入契约.md)、[L1](../03_测试模型Prompt/公开契约/A_L1.md)、[L2](../03_测试模型Prompt/公开契约/A_L2.md)。

## 2. 原工程事实边界

旧报告的查找线索：`Scripts/Import/Tree_LOD.gd`；`Materials/Tree branch LOD.tres`。

报告只读到导入脚本和 LOD 材质片段；哪些模型绑定该脚本、最终实例层级、真实切换距离及全部活动材质均待核验。300/500 只是既有报告中的脚本值，不作为运行时真值。

构建前必须补齐：

1. 同一完整提交中至少找到一类真实具有两个可观察表示的目标树，记录所有生效表面/材质和切换区间。
2. 确认目标逻辑根节点、参考空间、实例变换和中性发射锚点；初版锚点选在实际不受局部顶点风变形的稳定枝干区域，不能冻结全森林风动。
3. 确认共享资源的非目标树作为对照，记录原裁切轮廓、风动、阴影及 LOD 基线。若无法找到合适目标则阻塞 native 发布。

只把完整核验记录写入对应source_binding，不自行把这些线索升级为verified。场景细节见[A_L3场景规范](../02_场景文件与资源/A_L3.md)。

## 3. Codex参考实现职责

作者参考以逻辑树身份维护 A 状态，按每个活动表示的对象到统一参考空间变换求值，不能要求不同 LOD 顶点索引相同。锚点事件账本独立于具体绘制节点，CPU 可记账，余烬场与积分在 GPU。检测既读取同一参考点的数值，也检查实际被绘制表示的材质参数/原始状态与图像贡献，拒绝只更新诊断缓冲的实现。

需要新建的作者产物：`author/references/A_L3/`中的独立参考与GPU合格集成；`author/cases_private/A_L3/`的正式输入/答案；`author/judges/A_L3/`的oracle及采集；`author/mutations/A_L3/`的反例；`starters/A_L3/`的净化完整工程。这些是目标路径，不是已经存在的实现。

## 4. 十组正式集成覆盖

| 覆盖组 | 干预/输入设计 | 硬性判定 | 真实观测 |
| --- | --- | --- | --- |
| A_L3-G01 目标树静态接入 | 近距离固定时间，至少一目标树和一非目标树 | 灼烧/余烬实际进入目标材质及粒子资源；非目标保持基线 | 烧焦状态、实际活动材质、出生日志、目标/对照帧 |
| A_L3-G02 覆盖所有实际表示 | 逐个采集核验过的表示及可见区间 | 各表示按自己的基线表达同一目标状态，不能漏远景 | 表示 ID、参考点值、逐表示覆盖误差 |
| A_L3-G03 冻结状态跨越切换边界 | t 固定，相机往返跨实际边界 | 仅表现精度允许改变，b/a 不重置或消失 | 切换两侧序列、状态缓冲 |
| A_L3-G04 正常运行时切换 | 时间继续，往返并停留在过渡区 | 粒子不重复出生；焦化按同一时钟继续 | 复合粒子 ID、birth_time、age、轨迹 |
| A_L3-G05 离屏后返回 | 离开目标可见范围若干模拟 tick 后返回 | 不可见不暂停状态/重触发事件 | 连续参考轨迹与返回状态 |
| A_L3-G06 同资源多实例 | 两棵目标不同起点/种子，一棵共享资源对照 | 两目标互不串色/串发射，对照不受影响 | 按 object_id 对齐的 b/a 和资源影响图 |
| A_L3-G07 仅改变余烬参数 | 灼烧固定，改变 curl 或关闭新发射 | 灼烧状态不改；存量连续、无新发射 | 核心回归与出生/运动状态 |
| A_L3-G08 重置与重复绑定 | 相同配置 reset 重放；绑定显示接口但不 reset | reset 可重播；纯重绑定不得重新开始 | 账本、对象引用、状态 hash |
| A_L3-G09 原表示和风动保护 | 关新增显示但保留提交配置，运行原风动/切换 | 裁切、风动、阴影和切换机制未被改坏 | 原生属性、保护视图、源文件 diff |
| A_L3-G10 干净重导入与预算 | 清缓存导入同一源提交，再按路径运行 | 效果/状态和绑定复现，未依赖缓存且符合预算 | 导入记录、状态证据、资源/帧耗时 |

每组具体数值、采样点、原目标节点、随机种子、容差、时刻和参考输出均需作者补齐。不得把G编号、私有样本或标准答案作为候选运行输入。组内同时检查效果存在，避免空提交“没有越界所以合格”。

## 5. Oracle与误判控制

CPU 独立执行 A_L1/A_L2 契约，按 object_id 对齐事件；作者私有绑定表记录真实表示组与对应变换。每级图像与该级原始基线、该级合格参考比较，而非将近/远网格直接做像素差。跨表示比较低频焦化覆盖、前沿位置及查询值；像素较小的远景用已标定可观察范围，不凭空要求不可辨细节。

每级独立材质、共享核心配合实例参数或其他表示均可；只要同一逻辑状态成立且保持原调度，不因实现文件结构不同拒绝。远景低频简化按该级可观察容差判定。

按照[通用L3协议](02_L3集成检测通用规范.md)验证GPU实际资源、正常计算与显示一致性；用[工具协议](../04_作者侧流程与评测/05_L3工具与检测协议.md)分离公开诊断和私有裁判。

## 6. 必须构造的错误对照

1. 只给近景 Mesh 换材质。
2. 每个 LOD 各建独立发射器，切换时重新出生。
3. 不可见时停止时钟，返回时 reset。
4. 修改共享材质使非目标树一同焦化。
5. 关闭 LOD/风动或填实 alpha 裁切来掩盖问题。

为每个反例记录至少一个预期拒绝的G组，执行后保存证据；不能只写“应该能测出”。至少另一种合法实现或组织应通过，避免裁判只识别作者文件结构。

## 7. 视觉与保护rubrics

1. 近远各表示均可辨同一灼烧阶段，而非远景恢复原色。
2. 余烬从当前前沿出生，过渡时没有异常爆发或跳回。
3. 原森林轮廓、风动与非目标植株保持正常。

采用原包0–4锚定视觉等级和固定相机/时刻采集；最终视觉阈值先标定后冻结。数值、核心联动、静态/运行时保护失败不由视觉分抵消。

允许：在目标实例内绑定 solution 中的新材质/实例参数和余烬子节点；保留原风动、裁切、LOD 与非目标消费者。

禁止：修改源树模型、重命名导入依赖节点、改变 LOD 阈值/可见性、共享资源全局改写、改环境/相机。

## 8. 输出与发布

真实输出至少包括：`logical_burn_state`, `active_representation_materials`, `birth_and_particle_state`, `protected_tree_runtime_snapshot`。数据必须关联实际资源、坐标、格式、对象ID和tick，并与画面干预同步，不信任模型自己填写的pass/fail。

发布前仍需冻结：targets_and_reference_frames, effective_lod_ranges, anchor_region_validity, state_error_tolerances, representation_visual_tolerances。依照[L3门禁](../04_作者侧流程与评测/06_L3发布门禁与评分.md)运行全项。缺源/不具备观测条件标阻塞，不部署只包含题面但没有工程的任务。
