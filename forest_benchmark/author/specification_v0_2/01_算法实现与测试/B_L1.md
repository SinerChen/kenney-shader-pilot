# B_L1｜持久化脚印压痕与 POM：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：投影印章＋有界高度累积＋视差遮蔽映射。约束映射：F02。前级：无。

## 1. 目标与边界

根据给定接触事件在测试泥地生成可累积的脚印。接触位置、方向、尺寸和深度改变持久化高度场；使用 POM 呈现随视角变化的压痕深度，不能仅贴一层黑色图案。

本级整个测试地面均可踩压，无地形材质分区。视觉高度/POM 不改变真实地面网格、阴影几何或碰撞；不要求真实土壤变形。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| B_L1-N01 无事件 | 全零初场，无 contact | depth=0，POM 基准命中 |
| B_L1-N02 单印章 | 轴对齐单接触 | shape、depth 和单位 |
| B_L1-N03 位置 | 平移印章 | 位置和非目标区域不变 |
| B_L1-N04 方向 | 非对称鞋底旋转 | 不能忽略角度/轴向 |
| B_L1-N05 尺寸 | 改变长宽，中心固定 | 缩放及接触范围 |
| B_L1-N06 重叠 | 多 ID 脚印相交 | 有界累加 |
| B_L1-N07 地面边缘 | 印章跨出域 | 裁切、不 wrap |
| B_L1-N08 最大深度 | 大量重叠 | 饱和到 d_max，无负深度 |
| B_L1-N09 POM 命中 | 已知坡面/台形场、正视与斜视 | 最早交点及误差 |
| B_L1-N10 持续性/去重 | 同 ID 重发、无事件推进 | 不重复踩踏、不丢失状态 |


这些是覆盖类别，不是已跑的 10 个输入。作者固定实际数值/种子，另给不重合的公开开发样例。失败时保存逐输出误差和原始值；不只返回一个布尔。

## 5. 参考结果与独立性

印章 CPU 参考按明确 texel 中心和双线性采样计算。POM 用高精度密集区间扫描加局部根细化；作者另用常量深度/倾斜平面解析解核验。台阶边缘选有限连续插值场；不能要求在不连续根处虚假的精确度。比较 UV/米制深度，不只颜色。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 7. 必须构造的错误对照

1. 只画黑色贴花。
2. 每帧清空状态。
3. 重复应用相同 event_id。
4. POM 深度方向反了。
5. 只以 Vx/Vy 做常量偏移。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 脚印方向、形状及交叠清晰。
2. 斜视有深度而非涂黑。
3. 视角变化不让压痕漂离原接触位置。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
