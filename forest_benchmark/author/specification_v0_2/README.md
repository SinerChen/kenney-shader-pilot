## 测试设计数量

原有100个L1/L2算法数值覆盖组、25组L2联动保持。新增六个L3各10组集成测试，共60组；每题另回归前级20个数值案例及5组联动。L3共120/30次计划回归执行是重复运行，不是新增算法题。这些均是规格数量，不是已执行数量。

## 原包兼容与新增边界

L1/L2的公开数学契约与10份已组装Prompt保持v0.1原文，L3使用v0.2接入契约。原作者文档追加L3入口，通用权限、防泄露及release清单同步升级。

六项L3目前均需完整源工程绑定和运行核验。原报告只提供候选片段：未知节点/噪声文件/材质层不编造，F04缺少唯一世界云场映射则阻塞，F05/F06未挂载则不称原场景已存在。可以单独做constructed_fixture验证工具，但不可与native混报。

L3保留非目标原代码作为上下文，不机械删掉天空密度或水体光学；清理的是本级新增目标答案。E_L3不提供E_L2已经解决后景输入的公共桥，模型需完成本级接入。

## 校验与状态

[静态检查报告](04_作者侧流程与评测/PACKAGE_VALIDATION.md)只证明文档/清单一致性；本包带可实际运行的文档校验器[tools/validate_spec_package.py](tools/validate_spec_package.py)，不包含Godot测试命令实现。

运行：`python tools/validate_spec_package.py`。Godot导入/编译、GPU、60组集成测试、前级回归、视频和阈值标定均未执行。所有release lock保持BLOCKED_RELEASE，Codex完成后才可逐题激活。
