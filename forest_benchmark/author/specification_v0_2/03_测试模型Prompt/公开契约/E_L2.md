# E_L2｜交互涟漪与前景折射的正确组合：公开数值契约 v0.1


## 波动状态

水面 y=h(x,z)，正高度朝 +Y。状态 h_n/h_prev 为本轮真实 GPU 高度场；初始零，或输入给定。f_n 是本 tick 的外部扰动加速度场（m/s²），不是重复播放动画。事件通过公开空间核和唯一 ID 转成 f_n，仅持续所指定 tick。

本版格式 `h_next=(2-gamma*dt)*h_n-(1-gamma*dt)*h_prev+c²*dt²*Laplacian(h_n)+dt²*f_n`，gamma>=0。X/Z 五点差分使用真实 dx/dz。边界零法向导数（缺失邻居取边界值），表示本版反射边界，不测试开放吸收边界。

合法测试域满足 `c²*dt²*(1/dx²+1/dz²)<=0.8` 且 `gamma*dt<=0.1`。作者配置另限制总高度以符合小振幅近似。不得 clamp 高度来掩盖不稳定；超出输入域由 harness 拒绝。

法线从当前用于显示的高度计算：`n=normalize((-dh/dx,1,-dh/dz))`，内部中心差分；边界用与上述 ghost 规则一致的差分。本级法线和位置状态均可查询。为避免扩展到额外几何预算，视觉主要求是高度驱动的法线波纹；微小真实位移可实现但不额外加分，数值 h 必须真实存在。

## 渲染关系

后景水面使用本轮波面法线和继承 E_L1 的光学核心着色，后景还包括不透明标记。只读支架先捕获该后景，再供前景 E_L1 读取；支架不提供波动、法线、Fresnel 或折射解。前景不得出现在其自己的背景输入里，避免递归反馈。

接口 `wave_step(h_n,h_prev,f_n,params)` 输出 h_next；`wave_normal_query` 输出 n；运行证据包括 rear_color_current、front_background_used 和两个光学消费者。捕获帧与模拟 tick 一致，不准只读取初始化截图。前景几何变化不能反过来改写后景波状态。
