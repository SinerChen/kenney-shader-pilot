# L3 公共接入契约 v0.2

## 信息、继承与输入环境

本级输入是已封存的本链 L2 solution，以及列入清单的完整森林项目上下文。只含经清理的非目标既有代码和本级允许资源，不含本级参考解。你可以读取原场景/资源/材质/脚本来理解接入关系；既有系统中明确保留的代码允许复用。不得联网取得完整目标实现或读取其他任务/模型结果。

本级不提供已完成本级集成的适配器。逻辑接口可读原始场景输入并进行范围受限的绑定，不替你计算区域许可、状态对应关系、光程或所需的完整后景。

前级数值与联动定义继续生效。测试环境会把你的数学核心按公开标准接口放回前级规范化输入中检查，同时单独运行本级原场景接入。本级列明的坐标/边界/原材质扩展仅作用于场景接入，不得悄悄改写前级标准函数。

## 工作区和原场景

工程入口仍为 `res://fixture/entry.tscn`，它装入 `public/scene_inventory.json` 指定的真实源入口以及 `solution/effect.tscn`。原工程文件维持原本的 `res://` 根相对路径，实际目录以清单为准，不能假设只存在 assets/ 和 fixture/。

除 solution/**、scratch/** 与工具管理的生成缓存之外，默认全部只读。原场景 `.tscn`、材质、Shader、纹理源、导入描述和 project.godot 均受保护。缓存可生成但不能作为提交源码、越权补丁或预存测试答案。自有临时诊断不得写入原资源。

新增逻辑和资源放在 solution 内，允许修复继承代码。`public/permissions.json` 精确给出可绑定的对象、属性、材质表面或渲染资源范围；原文件只读不代表完全不能在授权位置绑定新增效果。未授权的变换、可见性、材质、时钟、灯光/天空/曝光/AA、相机与原行为都不得改变。主相机和只读环境不可改；本级明确允许的离屏相机副本除外。

## 接口和证据

保留 reset(config)、advance(dt,events)、query(name,payload)、get_outputs()。本级 adapter 还须实现 `bind_scene(scene_access,task_config)` 与 `detach_scene()`，具体签名以只读基类为准。bind 只连接公开输入和权限，不应无条件 reset 正在运行的逻辑状态；reset 才开始新运行。detach 卸载本次新增绑定/资源，恢复授权修改前的引用，不能把原源文件重新写入掩盖越权。

get_outputs 需提供实际 GPU 场/纹理/粒子资源及对应模拟时间和场景对象 ID，便于测试工具读取。标识文字、手工 JSON 和截图不能代替实际数据；query 标准算法使用相同数学核心，场景状态查询读取正在驱动画面的真实状态。禁止根据正式测试名称、答案或运行模式选择一套专供判题的替身实现。

只有 advance 推进模拟。多相机或多次捕获应观察同一时刻，不能每渲染一次就重复事件或再次更新。合法缓存要满足公开时间/误差规则，未声明的一帧滞后不自动视为正确。

## 合法输入与评价

目标对象、坐标单位、允许变换、时钟/事件域、视觉目标、误差与预算均在发布 task.json 及专门配置中说明。正式测试不使用未声明的奇异输入，也不临时增加复杂流体或无限透明层要求。缺少必要输入或权限时报告实际阻塞，不自行删除目标或替换场景。

评价分别报告前级20个数值案例、前级5组联动回归、本级10组集成覆盖、实际视觉表现、静态文件/运行时保护与预算。组数是评测结构，不向实现提供正式输入索引或答案。允许算法/工程组织存在合法替代；非考点文件名不决定正确性。

保持必要效果强度、数量和覆盖范围，不能通过不生成效果、关光学、隐藏目标或关闭原功能通过保护检查。合法的局部反射/遮挡不要求所有非目标像素完全不变，按公开属性及隔离条件检查。
