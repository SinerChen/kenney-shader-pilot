# L3 完整森林工程组织、权限与答案清理

这是新建工作区的组织规范，不是本包已包含的场景文件。本包不携带第三方森林资产或可执行 Godot 项目。

## 1. 保留原工程的资源根

不要把整个原森林随意搬到 res://scene/ 再假定所有 res:// 路径仍成立。模型工程根保留原有文件布局，实际目录名由源清单生成；新增的fixture/public/solution等先检查命名冲突，若冲突则版本化改桥口并同步全部清单。

```text
work/
  upstream_forest/                 # 作者只读原提交，不挂给模型历史
  author/
    source_audit/                  # 绑定、原数据oracle、许可证和补丁记录
    baselines/native_normalized/   # 固定引擎导入/无目标诊断后的基线
    references/<L3_ID>/            # 私有合格参考与候选反例
    judges/<L3_ID>/
    cases_private/<L3_ID>/
  starters/<L3_ID>/               # 基于净化后完整森林的实际Godot根
    project.godot                 # 作者冻结，原设置保留
    <原入口/原资源目录>/           # 原相对路径保留；确切名字待核验
    fixture/entry.tscn             # 实例化确切源入口和solution
    fixture/scene_access.gd        # 原始访问及受限绑定，不实现本级求解

    scratch/
  runs/<run_id>/
    model_workspace/              # 仅此范围给被测模型
    private_results/              # 不挂给模型
```

目录中的占位符仅是作者计划，发布后的路径必须真实、精确且hash可复核。源入口从完整checkout读取，不因静态报告提到Main.tscn就跳过核验。

## 2. 四类原内容

1. **保留的上下文**：原树LOD/风动/裁切、地形混合、天空密度和时间、原水体光学/透明等与本题场景相关的非新增能力。保留源代码便于理解工程，不把它们一律当泄露删除。
2. **继承的前级解**：只来自本run的指定L2快照；C两个变体都从相同C_L2开始，不彼此继承。
3. **必须清除的新增目标答案**：任何已经完成本题LOD灼烧同步、区域脚印/湿润、原天空云影适配、源坐标/泡沫适配或前景完整捕获的现成逻辑、缓存、禁用节点和烘焙结果。若原工程天然含有本题完整答案，先分离不破坏上下文；分不开则标方案冲突，不宣称无解泄露。
4. **纯输入与基础设施**：中性几何、原纹理、物理流场、事件、参数、时间和相机元数据。桥层不能直接算好H、源投影、原场到世界密度映射或完整前景背景。

E_L3 不继承 E_L2 作者提供的完整层捕获fixture；保留模型自己的光学/波动数学代码及接口。本级允许模型自行重构自己的渲染实现，公共输入不先解决缺层问题。

## 3. 权限

所有原文件默认只读；模型只能写solution/scratch。通过公开binding权限在明确目标上连接新材质/参数、局部效果节点或渲染资源。授权对象必须列node path+surface/property+允许操作；不是任意SceneTree写权限。

允许的原功能替换要精确记录：D_L3可替换目标流纹子功能但保留其他光学；E_L3只扩展原水波法线，不全局改透明性；B_L3保留原地形层定义。保护既包括字节diff，也包括实际运行时对象、共享资源、可见性和环境状态。

## 4. 源与任务归一化补丁

作者可能需要统一引擎导入、测试时钟或加中性观察物体。每一补丁记录目的、原hash/新hash、是否改变源行为、给模型的可见性和验证结果。先应用到对照基线再测试；不能只给参考解享有特殊桥或数据。

若人为挂载源库中未使用的River或构造有限云场映射，标 constructed_fixture 并写清改变，不能标为“原森林已有实例”。真实任务可以带作者新增测试物体，前提是核心被测系统确实来自已核验原绑定；记录test_interventions而非隐去它们。

## 5. 发布前导出

保持足够完整非目标场景上下文；剔除.git、作者文档、私有oracle、过往模型结果、目标实现及远端取回答案的通道。逐文件声明source_context/inherited_solution/neutral_input/public_fixture。原始资源import描述保留，缓存可重新生成；干净重导入结果需与规范化基线一致。

原资产许可证、署名和可再分发范围逐项核验。未经授权的资产不打包给模型；私有本地可用与公开可再分发不是一回事。缺失许可可阻塞公开发布，不虚构可用路径。

## 6. 前级文件依赖和入口迁移

封存L2 solution后，枚举它实际引用的中性资产、include和公开接口。需保留的合法依赖放到不冲突的精确路径，提供原路径到新路径的迁移清单；不得静默遗漏引用文件、改数学或把作者L3适配解补进继承代码。记录原predecessor hash、仅基础设施迁移patch hash及迁移后的hash。

原森林基线入口必须可以单独启动。L3未完成绑定时由公开空接口明确返回UNIMPLEMENTED_BINDING，不用缺失脚本/类制造无法导入的基础设施。旧L2具体舞台节点不必在L3伪造存在；候选需要自行适配目标场景，但能读到明确的输入/API变更。

E_L2已完成后景捕获fixture必须剔除；留下同签名的空输入槽/能力说明，不留下可直接运行的原捕获逻辑。模型自身实现的光学/波动代码保留。相同迁移规则用于self/gold，不能只给参考解提供特殊依赖。私有前级回归另外加载标准L1/L2夹具，不把完整夹具并入L3求解上下文。
