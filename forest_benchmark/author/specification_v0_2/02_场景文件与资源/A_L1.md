# A_L1｜场景文件、资源与绑定

**本文件是作者侧建场景清单，不是现成工程目录。** 原森林路径与本轮新建路径不能混淆。

## 1. 场景职责

在给定单一木质物体上实现从指定位置扩展的程序灼烧。使用给定变体的三维梯度噪声/fBM 扰动空间前沿，区分未灼烧、活动前沿、已焦化状态；正确响应位置、时间和参数。不得用预制灼烧动画或整体变色代替。

本级不包含的内容：单一网格、单一材质、无 LOD。几何保持完整；不要求真实燃烧化学、断裂、碰撞或火焰流体。三维模式固定在物体参考空间，镜头改变不改变状态。

本场景使用合成最小舞台，非真实森林 L3。无需原树模型；后续 F01 才核实多 LOD 表示。

## 2. 需要新建/准备的文件

所有工程相对路径均相对于 `starters/A_L1/`；`res://` 指该目录。通用 `project.godot`、`fixture/entry.tscn`、`fixture/bridge.gd`、`fixture/adapter_base.gd`、`solution/effect.tscn`、`solution/adapter.gd`、`public/task.json`、`public/contract.md`、`public/api.md` 每题必须存在。

| 目标路径/模式（待新建） | 作用与允许内容 | 初始状态 |
|---|---|---|
| fixture/base_stage.tscn | 中性舞台、相机、灯、木块/圆柱，无目标 Shader | PLANNED；未随本包提供 |
| assets/wood_base.* | 基础木纹/粗糙度，或作者生成的中性替代 | PLANNED；未随本包提供 |
| assets/noise_permutation.json | P/G 数值输入，不含噪声函数 | PLANNED；未随本包提供 |
| public/burn_config.json | 美术及数值参数域 | PLANNED；未随本包提供 |


`.*` 只是待选资源格式，发布清单必须替换成确切名字、导入描述、哈希及许可。不得把没有验证存在的上游图像/模型写成已复制。中性替代资产由作者生成，并按 generated 标记。

## 3. 节点与接入

| 场景节点（作者应创建） | 权限 |
|---|---|
| Stage/TargetMesh | 保护目标/舞台；仅公开 bridge 授权的绑定或效果节点可改 |
| Stage/ProtectedControl | 保护目标/舞台；仅公开 bridge 授权的绑定或效果节点可改 |
| Stage/CameraRig | 保护目标/舞台；仅公开 bridge 授权的绑定或效果节点可改 |


材质和状态从 solution 的公开桥口接入指定目标。模型无需改只读舞台文件；桥口不得开放全局相机/曝光/光源修改权限。被标为“模型新建”的 EffectRoot 子节点须挂在 solution 管理范围。

## 4. 必须可采集的实际输出

- burn_state：实际 b/a GPU 输出
- material_channels：焦化色/前沿发光诊断

由作者桥层读取真实资源，并为每个浮点缓冲保存维度、通道、数值范围、坐标/单位、时间戳和原始数据。模型提供的说明文字不是结果来源。最终图片与原始数值分开。

## 5. 基础数据与算法的边界

输入资源只包含几何/图像/速度/密度/事件等本题已声明数据，不能提前包含目标状态或答案。例如发射锚点不能含 front，密度体不能含 T，速度图不能是泡沫录像。所有脚本检查内嵌 Shader 和禁用参考节点。

本级初始 solution 仅有合法签名和可显示的占位几何。未实现查询必须报 NOT_IMPLEMENTED，不能返回让零输入测试偶然通过的硬编码答案。

## 6. 拍摄与保护

至少一个正常视角、一个能显示目标变化的侧/斜视或参数序列、一个保护对象区域。相机位置/路径、采样时刻、曝光、色调映射和 AA 在发布配置固定。不将正式隐藏事件序列文件装入模型工程；测试时由隔离 harness 注入。

保存效果关闭基线、公开运行样例和合格作者序列；参考序列只在作者评测端保存，默认不给模型。对受保护对象的视觉差异按授权语义解释，不强求合法折射/遮挡影响为零。

## 7. 最终验收

本题需做到：路径全部存在；导入无错误；空白接口与目标算法边界清晰；GPU 输出格式验证；目标可通过合法接口接入；非目标运行时属性未变化；干净重导入复现。运行失败须区分基础设施问题和候选实现问题。
