日期：2026-09-26。

## 范围与证据边界

本轮是有限的静态检查，不是完整工程运行审计。普通网页读取了项目配置，以及固定提交 `ac523ed97ca1719f517cd3968f3ff49d76274baa` 中可显示的代码差异。完整 Main.tscn、所有 Shader 主体、GLB 几何与运行时绑定未全部取得；未运行 Godot，也未检查用户修改后的实验工作区。

下面六项是有指定源码片段支持的集成约束候选，不是六个已复现 bug。原场景可以正确运行；后果指新增效果忽略这些条件时可能发生的错误。测试与阈值均未实现或校准。

## F01 — 跨 LOD 表示的效果状态一致性

### 已读取的事实

- `Scripts/Import/Tree_LOD.gd`，新版本原文件行 4–25：导入脚本按直接子节点的 LOD 名称后缀分配 300/500 距离段。 [S1]
- `Materials/Tree branch LOD.tres`，新版本原文件行 1–9：存在 LOD 专用 ShaderMaterial 及其纹理引用。 [S1]

**绑定边界：** 尚未读取各 GLB 的导入绑定及运行时节点；不能断言所有树都启用了此脚本。

**候选效果：** 给指定树木增加积雪、苔藓或灼烧状态，并在远近观察时保留同一语义状态。

**简化假设：** 修改当前可见的一个 Mesh 或材质就等于修改整棵树。

**后果推断：** 切换到另一 LOD 后效果可能恢复原样、重复或失去附着；任意改名/改层级还可能改变导入脚本分类。

**结果约束：** 所有生效表示应在规定距离维持目标状态；允许远景简化细节，但不得恢复错误状态或取消原有 LOD。

### 拟议检测

1. 先枚举目标树全部生效 LOD、材质和实际距离段，不能仅凭脚本默认值假定运行状态。
2. 固定效果参数及时间，让相机往返穿过实际切换边界；记录当前表示和各表示上的效果状态。
3. 比较每级在效果关闭/开启时的差异，而不是要求不同网格逐像素相同。
4. 在授权副本中重新导入并重启，再执行相同测试，确认提交不依赖临时导入缓存。

**错误对照：** 只修改近景表示。

**合法替代：** 各 LOD 可以使用不同复杂度的实现，只要符合任务规定的状态与连续性。

**保护范围：** 非目标树木；原 LOD 调度；未授权资产命名与层级。

**阈值：** 待合格实现、错误对照与原场景切换基线共同标定。

**引擎机制参考：** D1, D2

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。


## F02 — 分层地形材质的区域语义约束

### 已读取的事实

- `Materials/Terrain 1.tres`，新版本原文件行 3–8：材质引用两张 splat 图、纹理数组及 Blend8 splat Shader。 [S1]

**绑定边界：** 材质资源配置已确认；它与主场景具体地形表面的绑定、各层语义及混合公式仍需核验。

**候选效果：** 仅在题目标定的泥土区域形成湿痕或脚印，保护石质区域与其他地表层。

**简化假设：** 同一个地形 Mesh/材质名代表同一种地表；随意使用一张遮罩的单通道即可。

**后果推断：** 新效果可能覆盖错误材质层、跨越禁止区域，或通过替换整个地形材质破坏原有混合。

**结果约束：** 新增区域效果依据实际生效的层/区域定义定位，并保留不属于任务目标的原始混合表现。

### 拟议检测

1. 完整读取 Blend8 splat Shader、纹理数组导入设置和实际材质绑定；明确层索引、通道、UV 及混合规则。
2. 建立人工核验过的层内部、非目标层内部与过渡区域采样点。
3. 测量合法区域的效果覆盖与禁止区域泄漏；不能把所有软混合边界直接二值化。
4. 审计材质是否被整体替换，并对保护区域进行受控回归。

**错误对照：** 在整个地形表面统一变湿或使用未经验证的通道生成遮罩。

**合法替代：** 允许不同算法计算区域，只要输出遵守已公开的层语义及过渡规则。

**保护范围：** 原地形层混合；非目标地表区域；原地形贴图与未授权通道。

**阈值：** 待标定；本轮没有确认任何通道代表泥土或石头。

**引擎机制参考：** D3

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。


## F03 — 图像文件与 GPU 资源类型不等价

### 已读取的事实

- `Main.tscn`，新版本原文件行 3–6：天空引用中同时存在按 3D 资源加载的 TGA 噪声与按 2D 资源加载的 BMP 噪声。 [S1]

**绑定边界：** 主场景中的资源引用已确认；完整运行时消费者及所有采样路径未核验。

**候选效果：** 复用允许的现有噪声素材增加局部雾或其他程序效果，同时保留原天空。

**简化假设：** 常见图像扩展名等同 sampler2D 输入；为了新效果可以直接改原文件导入模式。

**后果推断：** 层/切片采样可能错位，或者新效果可用但原天空消费者受到破坏。

**结果约束：** 复用前正确识别类型、维度、层数与采样语义；不得越权改变既有消费者依赖的导入结果。

### 拟议检测

1. 清点资源实际类、尺寸、层数、导入设置及引用者，而非仅按扩展名推断。
2. 在多个坐标/层位置核验新增算法的采样结果。
3. 关闭新增效果但保留其资源改动，检查原天空和地形的回归。
4. 在干净导入后重复测试，确认资源类型和内容契约仍成立。

**错误对照：** 把切片资源当作普通二维图采样，或直接修改原资源导入类型来满足新增 Shader。

**合法替代：** 允许在授权目录制作正确的独立资源转换或副本；不强制唯一 sampler 实现。

**保护范围：** 原资源导入类型与切片组织；已有天空及其他消费者。

**阈值：** 类型/维度为明确契约；数值容差及视觉回归容差待标定。

**引擎机制参考：** D3

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。


## F04 — 新增云影与既有天空状态的时空一致性

### 已读取的事实

- `Shaders/Sky/sky volumetric clouds.gdshader`，新版本原文件行 210–217：可读片段包含时间缩放、时间偏移与方向相关的天气坐标计算。 [S1]

**绑定边界：** 主场景引用天空 Shader；实际显示参数、密度计算全流程和世界坐标映射未完整核验。

**候选效果：** 让地面新增云影与原天空云层对应，而不是绘制独立移动的暗噪声。

**简化假设：** 天空和地面各播放一个大致同向的噪声动画即可形成云影联动。

**后果推断：** 改变原云层相位、速度或方向后，新增地面阴影不跟随，或锁定屏幕而非世界位置。

**结果约束：** 在任务明确的光源与空间映射条件下，新增阴影受同一云场状态控制，且只影响授权光照贡献。

### 拟议检测

1. 先完整核验天空 Shader、实际 uniforms、云层高度/坐标约定及光源映射。
2. 分别干预云时间缩放、相位和方向，检查地面响应与该云场一致。
3. 在不改变云场时间的条件下移动相机，检查地面阴影是否保持世界空间锚定。
4. 采用云场调试数据与参考光路建立对照，而非简单匹配天空截图和地面像素。

**错误对照：** 使用另一张独立滚动噪声产生地面暗斑。

**合法替代：** 允许使用适合实时预算的云影近似，但题面须规定应保持的空间/状态关系。

**保护范围：** 原天空表现；全局曝光；非授权灯光贡献。

**阈值：** 未确定；云场到地面的空间映射本轮未完整取得。

**引擎机制参考：** 该项主要由工程片段提出；完整云场机制仍需继续读取。

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。


## F05 — 流动 UV 与世界空间交互锚点分离

### 已读取的事实

- `Shaders/River.tres`，新版本原文件行 30–37：可读顶点函数对 UV 做随时间变化的偏移。 [S1]

**绑定边界：** 仓库河流资源级证据；未确认主场景挂载位置和运行状态。

**候选效果：** 为固定入水物体添加接触泡沫源，并让浮叶按任务定义沿实际水域移动。

**简化假设：** 纹理流速就是世界速度，滚动水纹 UV 也可以直接承载固定接触位置。

**后果推断：** 固定接触源随纹理漂走；网格旋转/缩放后浮叶方向、尺度或速度不再符合要求。

**结果约束：** 区分图案采样坐标、表面局部坐标、世界锚点和真实状态；按题目定义建立它们的映射。

### 拟议检测

1. 先确认河流资源实际使用情况；未使用时仅作为资产级候选，不计入现有主场景发现。
2. 固定接触物体并改变纹理滚动速度，检查生成源是否仍锚定接触处。
3. 在允许变换范围内旋转/缩放测试水域，测量世界空间运动方向和速度。
4. 分别测量泡沫源的锚定与已生成粒子的输运，不把允许的粒子漂流误判为源漂移。

**错误对照：** 将接触源与水纹共用同一滚动 UV，或直接把 UV 参数作为世界速度。

**合法替代：** 根据任务定义可以允许泡沫本体漂流，但其接触生成源须正确锚定。

**保护范围：** 原有水纹流动；固定岸线/接触物体；非目标材质。

**阈值：** 世界距离、方向和速度容差待标定。

**引擎机制参考：** D5

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。


## F06 — 最终可见内容与屏幕采样数据不等价

### 已读取的事实

- `Shaders/River.tres`，新版本原文件行 33、76–81：河流材质读取屏幕纹理实现折射，并写出 alpha。 [S1]

**绑定边界：** 仓库河流资源级证据；完整挂载、渲染模式与重叠场景未运行核验。

**候选效果：** 将折射露珠、透明水花或局部扭曲与现有水体叠加，并正确保留被折射的目标水体。

**简化假设：** 最终画面可见的水体一定包含在新增效果读取的屏幕纹理中；仅调整绘制优先级即可补足所有内容。

**后果推断：** 新增折射区域可能跳过水体而显示更后的不透明背景，或多个屏幕采样效果不能按题目要求嵌套。

**结果约束：** 在约定支持的重叠关系下，新增效果使用包含所需对象的有效输入；不得隐藏水体或关闭折射伪装通过。

### 拟议检测

1. 先确认原水材质在运行时的渲染路径、实际截屏内容与项目后端。
2. 用带已知标记的水体作为新增折射物体的背景，建立不重叠/重叠及前后关系对照。
3. 直接观察新增效果采样的缓冲区是否包含水体，而不仅检查最终截图。
4. 按题面明确的透明组合深度制作参考结果；不得暗中要求无限层透明的精确解。

**错误对照：** 所有折射材质都仅使用不含所需透明层的同一默认屏幕拷贝。

**合法替代：** 允许经验证的额外捕获、分阶段合成或其他合法渲染结构，不强制唯一方案。

**保护范围：** 原水体可见性与折射；其他受保护对象；固定的渲染后端与画质条件。

**阈值：** 缓冲内容检查及视觉对照阈值待标定。

**引擎机制参考：** D4, D5

**状态：** 源码事实限于列明片段；后果未运行复现；检测仅设计。
