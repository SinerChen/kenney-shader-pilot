# 最小工程布局与文件权限

**下面全是 Codex 需要新建的目标路径，不表示本包已经包含 Godot 工程，也不表示原森林拥有这些文件。** 本轮不复制完整森林给 L1/L2。

```text
work/                              # 作者工作根，不整体暴露给被测模型
  upstream_forest/                  # 后续只读上游快照，需核实 commit
  author/
    references/                     # CPU/GPU 合格参考，私有
    judges/                         # 私有判题器
    cases_private/                  # 正式输入、答案、种子，私有
    mutations/                      # 故意错误的实现，私有
    baseline/                       # 原始快照、运行时保护记录
  starters/<TASK_ID>/               # 必须干净生成，不能从完整 author 工作区删减
    project.godot
    fixture/
      entry.tscn
      base_stage.tscn
      bridge.gd
      adapter_base.gd
    assets/                         # 仅中性允许资源及必要导入设置
    public/
      task.json
      contract.md
      api.md
      scene_inventory.json
      sample_inputs/                # 开发样例，不是正式 10 例
    solution/
      effect.tscn                  # 空目标节点；L2 装入前级产物
      adapter.gd                   # 签名占位；未实现时明确报错
    scratch/
  runs/<run_id>/
    model_workspace/                # starters 副本，唯一候选代码沙箱
    private_results/                # 不挂载到模型侧；裁判证据
```

模型仅可修改 solution/** 与 scratch/**。`effect.tscn`/adapter 是共同桥接入口，不允许为测试模型提前填入核心算法。不得留下 `reference*.gd`、禁用节点里的旧 Shader、材质内嵌源码、测试答案、仓库历史、预烘焙目标动画或模型结果。

L2 的 solution 从指定 L1 run 的已封存版本复制，保留来源哈希；不能误装入作者参考。L2 可修复前级但须通过相同 L1 回归。诊断条件 gold_predecessor 另建 run，从作者合格前级装入，仅包含前级解，不含本级解或测试；分别统计。

## 通用相机/灯/保护约定

每个 starter 具有一个目标区和至少一个非目标控制物体。公开文件列明可改变的效果参数和保护节点。作者相机/灯光/环境/分辨率固定，模型通过 solution 的指定绑定口接入材质或追加目标子节点，不改基础舞台文件。

若算法确实需要给只读目标 Mesh 绑定新材质，由 bridge 提供**范围受限的绑定操作**，不是开放整个 SceneTree 的修改权限。路径只读不代表运行时属性可任意改，裁判还要检测材质、可见性、变换和环境的保护状态。

## 资源分类

允许：通用几何、基础颜色/法线/粗糙度、鞋底遮罩、速度/密度输入、路径长度、材质外观端点、相机和光源数据、必要的纹理导入说明。

不允许作为 starter：成品灼烧/余烬/云影/流动/POM/折射/波动 Shader；目标高度/湿度/泡沫时序缓存；已经算出的发射区域、透射图、目标法线动画或参考截图。

源工程纹理可用时须核验许可和作用；未核验的先用作者生成中性资产。中性替代仍需记录来源，不能冒称取自森林。L1/L2 不应因上游缺少某一图像而携带整个目标实现。

## 导入与缓存

先在固定引擎完成导入，建立稳定基线。源 .import 描述是需保护资产；生成缓存按白名单忽略噪声变化，但最终必须从源文件干净重导入再运行。不能笼统忽略所有 .tres/.res/.tscn，也不能把引擎导入变化自动算模型违规。

清单中的 `.*` 或“可选”只表达作者待选择资源类型。发布后的 scene_inventory.json 必须全是确切路径、类型、哈希、许可和状态，不保留通配符，不引用作者机器绝对路径。
