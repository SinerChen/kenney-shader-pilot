# B_L2｜压痕约束的湿润扩散与干燥：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：二维扩散＋源项＋深度相关干燥。约束映射：F02。前级：B_L1。

## 1. 目标与边界

继承脚印深度和 POM，新增可注入、扩散和干燥的湿润状态。相同注水条件下，深压痕应按公开模型干得更慢；湿度同时影响材质表现。保留脚印，不用统一变暗代替状态演化。

使用本题简化标量模型，不模拟真实渗流、液面聚集或土壤水文。整个地面均为允许区域，材质分区留到 L3。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| B_L2-N01 零初场零源 | w=0,S=0 | 保持零 |
| B_L2-N02 只注水 | D=lambda0=0 | dt*S 和夹紧 |
| B_L2-N03 只扩散 | lambda0=S=0，局部非零初场 | 五点算子 |
| B_L2-N04 只干燥 | D=S=0 | 一步显式衰减 |
| B_L2-N05 深度作用 | 相同 w，两个 d 区域 | lambda(d) 和深处保留更多 |
| B_L2-N06 各向网格 | dx!=dz | 不能把像素间隔当一米 |
| B_L2-N07 零通量边界 | 湿度抵达边缘 | 无 wrap、无外流 |
| B_L2-N08 源饱和 | 强合法 source | w<=1，非源区域正确 |
| B_L2-N09 事件/多步 | 接触注水交错事件，持续推进 | 去重、dt 和使用当前 d |
| B_L2-N10 停源重置 | 停止 S 后继续；再 reset | 自然演化和无历史残留 |


这些是覆盖类别，不是已跑的 10 个输入。作者固定实际数值/种子，另给不重合的公开开发样例。失败时保存逐输出误差和原始值；不只返回一个布尔。

## 5. 参考结果与独立性

CPU float64 网格参考使用完全相同的离散格式。以均匀 w 场 Laplacian=0、D=0 的逐步标量衰减、lambda0=0 且无源的零通量总量作为自检；总量检查仅在没有 clamp 截断时适用。颜色相近不能替代状态比较。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 6. 联动/回归

| 组 | 受控干预 | 要求的关系 |
|---|---|---|
| B_L2-I01 深浅压痕 | 相同 w/S，改变 d | 干燥率和后续湿度按公式改变 |
| B_L2-I02 只换注水位置 | 固定接触深度和历史 | 湿痕起点变，脚印不被移动 |
| B_L2-I03 停源 | S 置零 | 继续扩散/干燥，不清零 |
| B_L2-I04 关扩散 | D=0 | 无邻域传播，源/干燥仍工作 |
| B_L2-I05 关干燥 | lambda0=0 | 无蒸发项，保持前级深度 |


另外重跑 B_L1 的 10 个数值组、视觉关键约束和保护项，单独报告 inherited_numeric_pass。联动组要分别运行 A-only、B-only/诊断与组合；B 的运动/存量不能因 A 关闭显示而被错误清空。

## 7. 必须构造的错误对照

1. 独立播放湿纹，不读取 d。
2. 全场降低粗糙度。
3. 每帧覆盖为当前水源遮罩。
4. 原地更新产生方向偏差。
5. 改变风格参数时悄悄改变湿度。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 湿润边界连续演化。
2. 深压痕保水差异可见但不造黑洞。
3. 湿度材质变化与 POM 脚印同时成立。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
