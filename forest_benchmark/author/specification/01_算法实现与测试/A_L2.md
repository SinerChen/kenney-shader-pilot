# A_L2｜灼烧前沿驱动的旋涡余烬：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：Curl Noise＋中点 RK2＋粒子生命周期。约束映射：F01。前级：A_L1。

## 1. 目标与边界

继承 L1 灼烧效果，新增只从当前活动前沿出生的余烬。使用 Curl Noise 速度场产生卷曲上升轨迹，按规定寿命冷却和消失。活动前沿与粒子出生位置必须真实关联。

不模拟真实烟/火流体。允许实例化小面片或 GPU 粒子容器，但内置粒子过程不能替代本题速度场和积分。保留原 L1 状态与接口。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| A_L2-N01 零速度场 | curl_strength=up_speed=0 | 位置不变、年龄增加 |
| A_L2-N02 纯上升 | curl_strength=0 | 线性位置、单位/方向 |
| A_L2-N03 旋度分量 | 固定 P/offset/epsilon，非对称采样点 | 三个 curl 分量符号和次序 |
| A_L2-N04 差分步长 | 同场改变 epsilon | 符合指定离散算子 |
| A_L2-N05 时变场 | 非零 drift | time 在两次 RK2 采样中正确 |
| A_L2-N06 多步轨迹 | 相同初态与一串固定 dt | 累计误差在预算内 |
| A_L2-N07 出生资格 | 锚点跨阈值，含禁用阶段 | 合法源、唯一 ID、不提前消耗资格 |
| A_L2-N08 死亡/冷却 | age 跨 lifetime | 边界 active/cooling |
| A_L2-N09 关闭发射 | 有存量时关闭 enable_emission | 存量继续运动，新粒子为零 |

## 5. 参考结果与独立性

CPU 参考复用作者侧噪声数学规范而不调用 GPU；先用常量/线性测试势场对 curl 算子做作者自检，再用真实噪声比较。发射 oracle 单独计算 A_L1 front，记录锚点首次满足条件的 tick。粒子顺序按 ID 对齐，不按绘制顺序比较。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 6. 联动/回归

| 组 | 受控干预 | 要求的关系 |
|---|---|---|
| A_L2-I01 移动灼烧起点 | 固定场与寿命，只改 origin_ref | 出生锚点/时刻随前沿变，非全局发射 |

| A_L2-I05 分离显示 | 分别关余烬可见性/灼烧美术显示，保持算法 | 状态依赖保留，不靠可见像素触发出生 |


另外重跑 A_L1 的 10 个数值组、视觉关键约束和保护项，单独报告 inherited_numeric_pass。联动组要分别运行 A-only、B-only/诊断与组合；B 的运动/存量不能因 A 关闭显示而被错误清空。

## 7. 必须构造的错误对照

1. 固定原点的粒子发射器。
2. 从已焦化全区域发射而不是活动前沿。
3. 关发射直接清空粒子。
4. Euler 冒充指定 RK2。
5. 每帧重复同锚点出生。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 余烬从当前燃烧边缘而非任意空间出现。
2. 卷曲运动和年龄冷却可读，不是统一闪烁。
3. 开关源与存量状态连续。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
