# A_L1｜程序灼烧与焦化：实现与测试

**读者：构建 benchmark 的 Codex/作者。不得给被测模型本文件。** 状态：规范已编写，Godot 实现、实际测试、阈值标定尚未执行。

算法：三维梯度噪声/fBM＋空间阈值前沿。约束映射：F01。前级：无。

## 1. 目标与边界

在给定单一木质物体上实现从指定位置扩展的程序灼烧。使用给定变体的三维梯度噪声/fBM 扰动空间前沿，区分未灼烧、活动前沿、已焦化状态；正确响应位置、时间和参数。不得用预制灼烧动画或整体变色代替。

单一网格、单一材质、无 LOD。几何保持完整；不要求真实燃烧化学、断裂、碰撞或火焰流体。三维模式固定在物体参考空间，镜头改变不改变状态。

## 4. 十个正式数值案例覆盖

| 正式覆盖组 | 输入设计（具体实例由作者私有生成） | 观测/判定 |
|---|---|---|
| A_L1-N01 禁用/未触达 | enabled=false 及半径尚未触达全部采样点 | b/a 均为零；不改基础材质 |
| A_L1-N02 无噪声前沿 | noise_amplitude=0，跨越球形前沿取点 | q、b、a 与解析值 |
| A_L1-N03 单 octave | 给定 P/G 与非整数三维坐标 | noise 与 CPU 独立参考 |
| A_L1-N04 多 octave | 改变 gain/lacunarity 与 octave 数 | 归一化权重、noise |
| A_L1-N05 种子变化 | 换一份合法 P，同一点集合 | 新状态对应新输入，不能固定贴图 |
| A_L1-N06 起点变化 | 改变 origin_ref | 空间前沿平移，噪声约定不变 |
| A_L1-N07 前沿边界 | q 接近 ±width、0 | 端点和过渡，有限输出 |
| A_L1-N08 窄前沿/负坐标 | 最小公开 width、负位置 | 索引环绕和过渡精度 |

## 5. 参考结果与独立性

以独立 CPU float64 实现规定噪声和前沿；用整数格点零贡献、无噪声球形前沿、b 的端点作解析自检。对同 config 的随机点、边界点和时间序列比较 GPU。数值 oracle 不能直接读取 GPU 结果作为期望。

完整误差规则、采集同步及 GPU 性能规范见 [通用测试规范](00_通用实现与测试规范.md)。数值容差、图像容差、运行预算未标定前本题状态为 BLOCKED_RELEASE。可以制作和测试参考，但不能出正式榜单。

## 7. 必须构造的错误对照

1. 全局 lerp 变黑，没有空间前沿。
2. 用随时间抖动噪声导致焦化回退。
3. 以 SCREEN_UV 替代物体参考坐标。
4. OJ core 正确但渲染只播放固定贴图。

每一种对照至少被一项预先标定的检测拒绝；使用相同舞台、输入与预算。允许的其他实现不能因文件名、循环顺序或非考点渲染结构不同而被拒绝。

## 8. 最终视觉 rubric

1. 三种状态可区分，前沿不是整个对象一起闪亮。
2. 不同起点和时间的传播变化符合目标。
3. 转动相机不改变灼烧图案在对象上的位置。

采用通用 0–4 锚定等级，记录证据帧/时间。VLM 只评价可见属性，不能根据模型自述判定 GPU 数学通过。数值/保护/联动失败不能靠美观抵消。
