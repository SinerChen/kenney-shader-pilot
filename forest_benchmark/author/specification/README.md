基于已确认的 F01–F06 前置任务方案。**5 条链、10 个 L1/L2 任务；100 个新增算法数值案例设计、25 组 L2 因果联动测试设计，另保留 50 例前级回归执行。** 它们是规格数量，不是实际执行或通过数量。

## 重要边界

本包是 **Markdown 实施规格和 Prompt 包**。不包含实际 `.tscn`、Shader 参考代码、运行中的 OJ 或第三方模型/贴图；这些由 Codex 按清单构建。文件检查通过不代表 Godot 测试通过。

数学变体、单位、更新次序和近似边界是为了可执行而在本次补充的 v0.1 约定，已单独标识。它们不改变已确认的五条效果链，但需要在作者参考验证后冻结。不要对外宣称本套是“只给算法名、毫无数值定义提示”的实验。

真实森林的 F01/F02 绑定、F03 的资源消费者、F04 的完整云场映射、F05/F06 的河流挂载尚未闭合。本轮合成最小场景可先做；真实 L3 没有被本包伪装为可投放任务。

## 实际交给 Codex 的一句话
