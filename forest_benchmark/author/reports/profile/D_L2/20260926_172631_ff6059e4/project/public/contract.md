## 公共适配接口

`adapter.gd` 的名字/签名由 starter 的只读基类规定，逻辑接口是：

- `reset(config)`：接受完整运行配置，清空状态，设置 t0。
- `advance(dt, events)`：处理起始时刻事件一次，再更新到下一时刻；不得按渲染帧率重复应用事件。
- `query(name, payload)`：返回指定 GPU 计算/状态的字段；不能以 CPU 重算另一份答案代替。
- `get_outputs()`：公开实际效果资源句柄和必要诊断元数据，由桥层采集。资源句柄不是 JSON 中的假数字，具体序列化由只读桥层完成。

核心计算/状态在 GPU；CPU 可调度、处理事件 ID、传参和记录。不得检测自己是否处于正式测试而切换为不同的数学实现。查询参数是正常算法输入，不含标准答案。

## 数据约定

除任务另行说明：世界 +Y 向上，地面 +X/+Z 为两个正方向；长度用米、时间用秒、角度用弧度。单位方向向量长度为 1。颜色计算在场景线性空间。非颜色输入禁止 sRGB 转换。

数值向量在 JSON 中为定长数组；GPU 原始标量默认 little-endian float32，索引为 uint32，布尔字段由元数据给出，不隐式混存。4×4 矩阵的序列化在 api.md 明确为列主序，作用于列向量；相机投影、视口 Y 方向和深度变换由锁定引擎的桥层元数据提供。不要把 Godot 内部布局或 PNG 行方向当成未声明约定。

二维场使用单元中心采样：`uv=((i+0.5)/Nx,(j+0.5)/Nz)`，按行 j 再列 i（i 最快）存储；尺寸、世界范围和 texel 间距由配置明确给出。三维场 i 最快、j 次之、k 最慢；每一轴坐标与元数据一致。纹理寻址/过滤由各题规定，不从文件后缀猜测。

输入必须有限且处于公开有效域；测试不会用未声明的 NaN、无限值或奇异变换制造陷阱。实现遇到无效输入应返回错误状态，不得悄悄输出“通过”。

# D_L1｜双相位 Flow Mapping 水纹：公开数值契约 v0.1


## 坐标与输入

水域有固定 XZ 平面基与物理长宽 Lx/Lz，表面坐标 uv 属于 [0,1]。流场是两通道线性浮点速度，单位 m/s，沿两条表面轴，不是颜色编码；按配置双线性采样。`v_uv=(vx/Lx,vz/Lz)`。纹理采样平铺 K 是独立正参数，不能当成物理速度。

给定周期 P>0、时间 t 和起始相位 phi（周数），`p0=fract(t/P+phi)`、`p1=fract(t/P+phi+0.5)`。本版 `w0=1-abs(2*p0-1)`、`w1=1-w0`。

两组采样坐标 `qi=K*(uv-P*pi*v_uv)`，基础颜色纹理 repeat+双线性；混合 `C=w0*Tex(q0)+w1*Tex(q1)`。各相位重置时该相位权重为 0，数值接口可显示内部 q 跳变，最终混合结果应连续。法线输入为线性编码的三分量切线法线（元数据说明是否 [0,1] 编码），解码后混合并归一化；不得对颜色调用 normalize。

输出 `uv_phase0, uv_phase1, weights, sampled_color, blended_normal`；流纹幅度不反馈修改原速度场。零速度时两相位采样相同，纹理不发生假流动。相同固定流场下整体在 P 后重复；纹理寻址正确处理负 q。

# D_L2｜固定接触源的泡沫输运：公开数值契约 v0.1


## 独立数据

源的坐标、泡沫状态采样域、Flow Mapping 图案 UV 是三种独立量。表面位置 s=(x,z) 用米表示，流场 v(s) 与 D_L1 相同输入。

泡沫 f∈[0,1]，初场为零或给定。源 `S(s)=sum(rate_j*max(0,1-(length(s-source_j)/radius_j)^2)^2)`，radius_j>0、rate_j 单位 1/s；source_j 为本 tick 固定世界点投影到表面基的坐标。关闭源仅令 S=0。

本版回溯 `q=s-dt*v(s)`（一次 Euler 回溯）；`f_next(s)=clamp(sample(f_old,q)*exp(-decay*dt)+dt*S(s),0,1)`。decay>=0。sample 在域内双线性、边缘夹到最近单元中心，q 位于域外时取 0（零入流），不环绕。源加入新时刻网格，刚生成泡沫从下一步起参与输运。

真实 dt、域长宽和速度共同决定输运，不能用纹理平铺 K 或相位 P 替代它们。半拉格朗日的数值耗散不自动违反本题；正式判题比较此离散格式，不要求严格质量守恒。

接口 `foam_step(f_old,flow,sources,config)` 输出 f_next/source_field；运行诊断分别公开 source positions、f、L1 phase UV。渲染的泡沫覆盖必须读 f，不能只画源遮罩。
