# 公共运行契约 v0.1

本文件定义输入、输出和权限，不提供目标算法实现。运行环境以 `public/task.json` 为准。若缺失、冲突或无法启动，报告原始错误，不自行更换引擎/渲染后端。

## 工作区

- `project.godot`、`fixture/`、`assets/`、`public/`：作者提供，只读。
- `solution/`：本题唯一源代码可写目录；L2 在这里继承本轮 L1 产物，可修复它但必须继续满足前级要求。
- `scratch/`：允许自己的诊断脚本和输出，默认不作为提交效果，也不进入最终评分采集。
- `.godot/` 等生成缓存由工具管理，不能通过修改它们或导入描述绕过源文件权限。
- 入口为 `res://fixture/entry.tscn`，它加载 `res://solution/effect.tscn` 和 `res://solution/adapter.gd`。这些路径是 starter 发布后必须真实存在的接口，不是原森林仓库路径。

可以新建材质、Shader 和局部效果节点，不能替换只读舞台、环境、相机、测试数据、评分工具或保护对象。不得联网拉取完整目标实现。可用普通向量运算、数学函数、纹理采样、基础绘制/引擎资源 API；不得以现成效果求解器替代本题被考核心。

## 公共适配接口

`adapter.gd` 的名字/签名由 starter 的只读基类规定，逻辑接口是：

- `reset(config)`：接受完整运行配置，清空状态，设置 t0。
- `advance(dt, events)`：处理起始时刻事件一次，再更新到下一时刻；不得按渲染帧率重复应用事件。
- `query(name, payload)`：返回指定 GPU 计算/状态的字段；不能以 CPU 重算另一份答案代替。
- `get_outputs()`：公开实际效果资源句柄和必要诊断元数据，由桥层采集。资源句柄不是 JSON 中的假数字，具体序列化由只读桥层完成。

核心计算/状态在 GPU；CPU 可调度、处理事件 ID、传参和记录。不得检测自己是否处于正式测试而切换为不同的数学实现。查询参数是正常算法输入，不含标准答案。

## 数据约定

除任务另行说明：世界 +Y 向上，地面 +X/+Z 为两个正方向；长度用米、时间用秒、角度用弧度。单位方向向量长度为 1。颜色计算在场景线性空间。非颜色输入禁止 sRGB 转换。

数值向量在 JSON 中为定长数组；GPU 原始标量默认 little-endian float32，索引为 uint32，布尔字段由元数据给出，不隐式混存。4×4 矩阵的序列化在 api.md 明确为列主序，作用于列向量；相机投影、视口 Y 方向和深度变换由锁定引擎的桥层元数据提供。不要把 Godot 内部布局或 PNG 行方向当成未声明约定。

二维场使用单元中心采样：`uv=((i+0.5)/Nx,(j+0.5)/Nz)`，按行 j 再列 i（i 最快）存储；尺寸、世界范围和 texel 间距由配置明确给出。三维场 i 最快、j 次之、k 最慢；每一轴坐标与元数据一致。纹理寻址/过滤由各题规定，不从文件后缀猜测。

输入必须有限且处于公开有效域；测试不会用未声明的 NaN、无限值或奇异变换制造陷阱。实现遇到无效输入应返回错误状态，不得悄悄输出“通过”。

# C_L1｜三维云密度驱动的地面云影：公开数值契约 v0.1


## 输入数据与坐标

`cloud_query(points_world,L,density,config)`。L 是从查询点指向光源的单位方向。云体有明确世界到局部的刚体变换、局部 AABB 和线性 float32 非负密度网格；本级只允许平移/旋转，不允许未声明的非均匀缩放。密度三线性采样；AABB 外为 0，内部边界夹到最近体素中心。每一轴坐标、尺寸、布局按公共契约。

光线 `r(s)=p+s*L, s>=0`。与云 AABB 求前向有效区间 [s0,s1]，无交或长度为零时 tau=0、T=1。光线起于云体内时 s0=0；各轴平行时必须正确处理是否在相应 slab 内。

本版正式数值查询指定分段数 N>=1，以 N 个等长区间中点采样。`tau=sigma_t_cloud*sum(rho(r(s_mid))*ds)`；`T=exp(-tau)`。sigma_t_cloud 单位 1/m，rho 无量纲。采样密度非负，tau>=0。输出 valid_interval、s0/s1、optical_depth、transmittance；无交时输出约定的 s0=s1=0 和 valid_interval=false。

最终云影只调制该方向光的直接贡献：`ground = base_ambient + T*base_direct`。base_* 由中性材质/灯光配置定义，不得通过把所有环境光乘 T 代替。视觉路径可在公开预算内增加采样，但 OJ 路径必须按输入 N 的定义计算并复用相同密度/光程核心。另用采样收敛验证视觉近似。
