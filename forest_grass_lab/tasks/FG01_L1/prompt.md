# FG01 · L1：让草随风动

在给定的 Godot 草地小场景中，实现持续、平滑的草地风动。效果要来自草网格自身的顶点运动，保留已有草地分布、草贴图、地面、相机与照明。

风向由 `wind_direction` 控制，幅度与速度分别响应 `wind_strength` 和 `wind_speed`。相邻草丛可以有相位差或传播感，不能让所有草始终像一块整板完全同步平移。连续运行不能出现跳变、闪烁或纹理脱离。

阅读 `HOST_API.md`。只修改 `project/effect/grass.gdshader`，使用宿主 `elapsed`。输出完整、可直接运行的 shader 代码。不得修改宿主与测试条件，不使用参考实现源码。
