# FG01 · L2：根部固定，顶部随风摆动

在你上一层 L1 提交的基础上改进风动，使草看起来扎根在地面上。保留 L1 的风向、风强、速度控制和平滑时间变化。

根部必须固定在原位置，不能在地面上滑动、漂浮或钻入地下；草叶从根部到顶部形成连续弯曲，顶部随风摆动。不能通过把整株草一起平移、将所有顶点冻结或仅改变贴图来满足要求。根部固定也不能以夸张拉长、断裂草叶为代价。

使用根部近景观察时，草根应一直与原来的地面标记对应；增大风强时顶部摆幅增加，根部仍保持固定。改变风向后形变方向相应改变；风强归零时恢复初始形状。

阅读 `HOST_API.md`。`UV` 是贴图坐标，`UV2.y` 提供归一化高度。只编辑 `project/effect/grass.gdshader`，输出完整实现；上一层存在的缺陷也可以一并修复。不加入玩家交互答案，不修改宿主或固定资产。
