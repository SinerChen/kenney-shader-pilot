# FG01 · L3：玩家经过后，草向外倒去并恢复

在你上一层 L2 提交的基础上加入玩家与草的交互。保留自然风动和固定根部，使用宿主提供的玩家位置、影响半径及最近轨迹，让玩家附近的草向远离玩家/经过轨迹的方向弯倒。

必须满足：

1. 玩家接近与进入影响范围时，附近草叶逐渐向外弯倒。路径两侧应朝各自外侧响应，不能整片草统一倒向同一方向。
2. 作用范围是局部的。远离玩家及近期轨迹的草保持 L2 风动；不能让全场地同时倒下，也不能仅改变颜色。
3. 草根仍然固定，顶部和中上部产生主要位移。草叶持续可见，不能通过隐藏、缩放为零或直接穿入地下来表示倒伏。
4. 玩家离开后保留短暂压倒痕迹，并在约 1–3 秒内平滑恢复到正常风动。不能在玩家刚离开作用圈时瞬间弹回，也不能永久趴倒。
5. 玩家停留、改变路径、反向再次经过时响应连续，不出现数值发散或严重跳变。风强为 0 时，玩家压草仍应有效。
6. reset 清除历史后，不残留上一次行走造成的压倒状态。

`player_history[32]` 只提供原始位置与时间，不包含完成的交互算法。阅读 `HOST_API.md`，只编辑 `project/effect/grass.gdshader`，输出完整可运行实现。可修复上一层问题，但不得修改玩家回放、相机、草分布和验收条件。
