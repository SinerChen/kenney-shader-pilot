# 案例详情展示

入口：[实验展示页](http://127.0.0.1:8771/index.html) · [项目内入口](http://127.0.0.1:8770/scene_algorithm_tasks/index.html)。选择模型和任务后，在同一详情面板切换以下内容：

- **效果视频**：实际候选工程的连续渲染。
- **Prompt**：本案例 `input.json` 中的 System / P3、User 题面和工具定义，可直接阅读、复制或打开原始 JSON。未运行案例显示已冻结的输入预览，并明确标注尚未发送。
- **调用轨迹**：按时间排列请求、响应、工具调用和错误；支持搜索、分页和 read / write / render / 错误筛选。展开可查看参数、完整写入内容、读取结果、工具返回、反馈图像及原始事件 JSON；完整 JSONL 仍可下载。
- **修改文件**：以本题开始时的 `initial_effect/` 为基准，显示新增、修改、未变更和删除，以及增删行数。可切换差异、当前内容与起始内容；成功写入记录可跳转到对应轨迹。L2/L3 使用实际继承后保存的本题起始快照。
- **过程截图、子任务计划**：保留原观察图像、模型自评计划和最终说明。

展示数据由 `tools/case_data.py` 从现有实验记录派生到 `runtime/cases/<模型>/<任务>/`；首页只读取索引，详情和每条原始事件按需加载。后台展示服务每 10 秒检查变化，页面每 15 秒更新；正在追加的 JSONL 尾行会等写入完整后再显示。

此功能不调用模型、不运行 Godot、不修改任务输入或候选文件。加密的提供方状态不作为可读模型文本展示，可在原始事件中保留查阅。

验证记录：[案例详情交互验证](../verification/case_inspector/validation.json)；测试入口为 `tools/test_case_data.py` 和 `tools/smoke_case_inspector.py`。
