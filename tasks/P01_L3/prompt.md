# P01_L3 · 材质收集庭院 · 材质、门与界面组合

保留 L1/L2。两次独立收集后，unlock 驱动 Gate 的能量材质启动，同时显示同步的进度与解锁状态；切换观察视角和 reset 后状态仍一致。

本任务使用固定的 Godot 4.6.1 / Forward+ 场景。先阅读 HOST_API.md 和本题 task.json。只修改分配的 effects/P01/ 目录，可增加该目录下的 shader 和辅助脚本；保留场景几何、资产、相机、事件协议及测试脚本。

在同一模型上一等级提交的文件上继续开发，保留前序要求；不得以参考答案替换上一等级结果。

验收要点：
- 前两级效果继续有效
- 门与收集进度共享一致状态
- 界面和三维效果不重复叠亮
- reset 恢复初始材质和计数

setup(context)、reset(state)、step(dt,state)、on_event(name,payload,state) 是统一入口。效果时间使用 state.elapsed，不依赖机器墙钟；事件目标名称与坐标以场景合同为准。输出修改后的完整文件，不输出仅说明实现意图的伪代码。
