# F01_L1 · 靶场命中反馈 · 选中目标描边

select 为指定靶标增加清晰的选中描边。保持主体原材质，轮廓随物体投影移动，其他对象不产生同样描边。

本任务使用固定的 Godot 4.6.1 / Forward+ 场景。先阅读 HOST_API.md 和本题 task.json。只修改分配的 effects/F01/ 目录，可增加该目录下的 shader 和辅助脚本；保留场景几何、资产、相机、事件协议及测试脚本。

从无目标效果的基线开始。

验收要点：
- 描边贴合目标轮廓
- 仅选中目标受影响
- 保留原有主体材质
- 移动相机后轮廓仍对齐

setup(context)、reset(state)、step(dt,state)、on_event(name,payload,state) 是统一入口。效果时间使用 state.elapsed，不依赖机器墙钟；事件目标名称与坐标以场景合同为准。输出修改后的完整文件，不输出仅说明实现意图的伪代码。
