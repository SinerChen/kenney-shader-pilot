# P02_L1 · 水面跳台 · 基础水面

为 Water 实现连续运动的水面法线、颜色与视角相关反射观感。保持水面边界与跳台布局，避免用整张屏幕贴图冒充水面。

本任务使用固定的 Godot 4.6.1 / Forward+ 场景。先阅读 HOST_API.md 和本题 task.json。只修改分配的 effects/P02/ 目录，可增加该目录下的 shader 和辅助脚本；保留场景几何、资产、相机、事件协议及测试脚本。

从无目标效果的基线开始。

验收要点：
- 波纹随时间变化
- 法线和光照关系一致
- 效果限制在水面范围
- 岸边物体保持可见且无明显穿插

setup(context)、reset(state)、step(dt,state)、on_event(name,payload,state) 是统一入口。效果时间使用 state.elapsed，不依赖机器墙钟；事件目标名称与坐标以场景合同为准。输出修改后的完整文件，不输出仅说明实现意图的伪代码。
